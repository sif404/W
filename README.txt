Amra City — Smart and Green Amra City Website

This is the full source code for the Amra City single-page website.

=== HOW TO RUN LOCALLY ===
1. Install Node.js from https://nodejs.org
2. In a terminal, in this folder run:  npm install
3. Then run:  npm run dev
4. Open the URL it prints (usually http://localhost:5173)

=== HOW TO BUILD FOR PRODUCTION ===
Run:  npm run build
The finished site appears in the /dist folder.
You can upload the contents of /dist to any web host (Netlify, Vercel, GitHub Pages, etc.).

=== FILES ===
- index.html         The entire website (HTML + CSS + JavaScript in one file)
- public/            Images (logos, author photos, favicon, social-share image)
- package.json       Project dependencies
- vite.config.ts     Build tool configuration
- tsconfig.json      TypeScript configuration
- src/               Original scaffold files (not used by the static page)
